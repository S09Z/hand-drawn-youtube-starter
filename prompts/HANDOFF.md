# Handoff Prompt

Prepare this repository for handoff to another agent. Do not implement new features.

Update `PROGRESS.md`, `TASKS.md`, and `AGENT_HANDOFF.md` only when necessary. Record:

- Last completed loop
- Current unfinished loop
- Decisions made
- Files changed
- Checks already run and their results
- Known bugs and blockers
- Rejected approaches and why
- Exact recommended next action

The repository must contain enough context for a fresh session to continue without this conversation.
