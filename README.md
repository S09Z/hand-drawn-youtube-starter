# AI-Assisted Hand-Drawn YouTube System

A lightweight workspace for producing short hand-drawn storytelling videos with AI assistance.

## Workflow

Research → Script → Storyboard → Drawing List → Procreate → CapCut → Publish → Analytics

AI prepares and checks information. The human owns creative direction, drawing, final editing, approval, and publishing.

## Start here

1. Read `AGENT_HANDOFF.md`, `PLAN.md`, `TASKS.md`, and `PROGRESS.md`.
2. Read the current file in `phases/`.
3. Inspect the repository without changing it.
4. Plan and complete one small loop at a time.
5. Verify, review, and record each loop before starting another.

The first recommended loop is `LOOP-01 — Repository Foundation Review`.

## Main folders

- `docs/` — channel and production rules
- `templates/` — reusable episode documents
- `episodes/` — one folder per episode
- `assets/` — reusable drawing catalog
- `research/` — shared research notes
- `analytics/` — performance records and lessons
- `wiki/` — lightweight Markdown/Obsidian knowledge base
- `prompts/` — reusable agent prompts
- `phases/` — scoped implementation plans

## Scope guardrail

Phase 1 is deliberately manual. Do not add Hermes, Telegram, scheduled jobs, a vector database, or publishing automation until the manual workflow has produced real episodes and exposed a real bottleneck.
